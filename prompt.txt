Build a complete production-ready web application using:

Next.js 15+ (App Router)
React
TypeScript
Tailwind CSS
PostgreSQL
Prisma ORM

The application should be a cute, romantic, mobile-friendly date invitation website.

General Requirements
Use modern UI/UX.
Responsive design for desktop and mobile.
Use Tailwind CSS.
Use Framer Motion for animations.
Use Server Actions or API routes to save data.
Use Prisma for all database access.
Follow clean architecture and best practices.
Use TypeScript everywhere.
Include setup instructions.
Include Prisma schema.
Include SQL migration.
Include environment variable examples.
Database

Create a Prisma model called DateResponse.

Fields:

id String @id @default(cuid())
accepted Boolean
dateTime DateTime?
activity String?
activityOption String?
createdAt DateTime @default(now())
User Flow

The application consists of 5 pages.

Each page should save progress to the database.

Use a unique invitation id passed through the URL.

Example:

/invite/abc123

The same invitation record should be updated throughout the flow.

Page 1 - Date Invitation

Route:

/invite/[id]

Design:

Cute centered card.
Soft modern colors.
Rounded corners.
Slight shadow.
Cute image at top.
Card width around 350-450px.

Content:

Will you go on a date with me? ❤️

Buttons:

Yes ❤️
No 🙈

Requirements:

The Yes button behaves normally.
The No button should playfully avoid the cursor.
When the mouse approaches within ~100px:
move the button to a random position inside the card.
never leave the card boundaries.
On mobile:
No button should move when tapped.
The interaction should feel playful, not frustrating.

When Yes is clicked:

Save:
accepted = true
Navigate to page 2.
